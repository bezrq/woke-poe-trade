_Requested by **Guy**_

Fixes the build set picker on real guide-style builds, and stale builds after saving in PoB.

- Colour codes are stripped from skill, item and tree set titles. Picks saved with them still match.
- `{3}` notes, `2 Stone` and `Day 3` no longer read as levels. A bare number only counts when the title starts with it.
- Endgame comes after the build's last levelling set, from level 70 at the earliest, so it no longer loses to a `Level 80` set.
- An untitled first set holds until the first titled stage, so a lone `Endgame` title doesn't win at every level.
- Empty sets are marked as headings and left out of chips and stage picks.
- The panel re-reads the selected build when its file changed, including on returning to the overlay. The active build is re-read when the overlay opens or an item is checked, keeps its object if nothing changed, and only the newest read counts.

Checked: adversarial review against Guy's 45 real builds at levels 1-100, full unit tests, `vue-tsc`, eslint, `vite build`, main `tsc`. Not tried in the game yet.
