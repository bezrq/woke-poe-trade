_Requested by **Guy**_

Fixes the build set picker on real guide-style builds, and stale builds after saving in PoB.

- Colour codes are stripped from skill, item and tree set titles.
- `{3}` notes, `2 Stone` and `Day 3` no longer read as levels. A bare number only counts when the title starts with it.
- Endgame now sits at level 85, past any `Level 80` set. Maps stays at 70.
- Empty sets are marked as headings and left out of chips and stage picks.
- The panel re-reads the selected build when its file changed. The active build is re-read when the overlay opens or an item is checked, and keeps its object if nothing changed.

Checked: unit tests, `vue-tsc`, eslint. Real titles from Guy's 45 builds were run through the old logic to find these cases. Not tried in the game yet.
