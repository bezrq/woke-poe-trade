_Requested by **Guy**_

Steps 1 and 2 of the [price data critique](https://claude.ai/artifact/1LS2iXRoSHqMWqpHg9fynH), WOKEPOET-81. No UI changes.

- **Bad replies:** a non-OK status, an error page, a cut-off body or a feed with no prices keeps the last good prices. It used to wipe them, count as an update and leave lookups blank for 31 minutes.
- **Retries:** a failure retries on the 4 minute timer, with at most one download a minute when price checks ask.
- **Startup AbortError:** asking for prices joins a running download. Only a league change, or a download stuck for 2 minutes, starts over. Errors no longer go unhandled, and loading no longer ends early.
- **League change:** the old league's update time no longer delays the new league, and moving to a league without prices cancels the old download, so it can't land or keep the spinner up.
- **Duplicates:** poe.ninja sends Currency and Fragment in both lists, so each type is now kept once. Saved snapshots correct themselves on the next refresh.

- **Market tracker price filter:** the doubled rows gave Vue repeated keys, so changing a filter left old rows on screen, as Guy saw at 500c min. Saved snapshots are cleaned when read. The c min floor now uses the price now, not the higher of then and now, so a fall from 1,115c to 394c no longer shows at 500c.

Not included: a restart while offline still has no prices in price check, though a snapshot is on disk. Expedition prices were already fixed in #146.

Tests: new `prices-fetch.test.ts` drives real `Prices.ts` with a faked network; 11 of its first 12 tests failed without the fix, and 2 more cover what review found. Full renderer suite, both typechecks, lint on `Prices.ts` and the Vite build pass locally. Nothing was run in game.
