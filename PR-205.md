_Requested by **Guy**_

## Summary

Guy asked for the Flips dock icon to trigger the stash outlines, and reported that Ctrl + F as the hotkey did nothing.

- **Icon click:** while playing, clicking the Flips icon now outlines the open stash tab, and clicking again clears them. Hovering still shows the card. With the overlay open, a click still opens the panel.
- **Clicks the game also got:** if the mouse was not taken, for example while a button is held, the game gets the click too and may walk away from the stash. Those clicks read nothing. The hover click event now carries `taken` for this.
- **Ctrl + F:** it is on the list of keys the game uses, so it was dropped with only a log line. Hotkey cells and the Hotkeys page now say "The game uses this key, so it won't work here". The Hotkeys page checks the whole key, so price check on hold Ctrl with F is caught and Ctrl + Home is not. The list moved to `ipc/KeyToCode.ts` so both sides share it.

Stacked on #204, so this should merge after it.

## Limits

- With "hover opens cards" switched off, a click opens the card as before, so the icon does not outline. The hotkey still does.
- A click within 400 ms of a clear does nothing, because one press reaches the app by two paths and that window tells them apart.
- The reserved key note was not seen on screen, here or on the Hotkeys page. Unit tests cover the wording and that every listed key matches the recorder's spelling, but no test renders the note.
- Not checked in the real app.
