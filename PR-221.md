Option G from the mocks: a tidier build panel, using the stats PoB saves in each file.

- Each row shows DPS and EHP as saved in PoB. The detail panel shows DPS, life, ES, EHP and resistances. PoB only saves these for the set active at save time, and the tooltip says which set.
- The panel opens on the build in use.
- One button, Use build / In use, replaces Make active. Show file and Follow moved into a More menu.
- When a character change switches the build, a toast says so and offers Undo.
