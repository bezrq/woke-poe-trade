_Requested by **Guy**_

Guy's report: the Settings "Text size" option makes windows bigger, not text. It set the root font size, and APT's windows are measured in that unit.

- **Text size** (new, 100-150%): scales font sizes only, everywhere, through `--w-text-scale`. Covers the `--w-fs-*` tokens, Tailwind `text-*`/`leading-*`, and all literal font sizes and line heights. Rows and one-line controls grow with it. Roll inputs and bulk ratio cells grow half as much so the window still fits.
- **Price check window size** (the old control, renamed): same `fontSize` setting, now shown as a percent slider, applied on release so the slider doesn't move under the mouse.
- **Panel size**: unchanged, hint reworded.

At 100% nothing changes. A unit test fails on any new literal font size or line height.

Checked at 150% on the fake game: price check (currency and rare), Settings, Loot filter and Map scan panels. Long mod names truncate sooner at 150%, since the window keeps its width; the window can be widened.

`app-icon.spec.ts` now clicks the visible label: the hidden radio was pushed off the scrolled area by the new row.
