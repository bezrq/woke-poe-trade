_Requested by **Guy**_

Second filter test PR: which block an item hits.

**Tests:** a copied item for every class NeverSink names (with and without the parser) at every strictness level, every base NeverSink lists read back under the filter's own name, each condition and operator, and how the file is walked. 918 new test cases. Only the 10 items in `testing/fixtures/items` are real game copies; the rest follow the game's copy format.

**Bugs found and fixed**
- `DropLevel` was never known, so every rule using it was undecided, and rare gear could show the wrong block. Adds a base table from RePoE (MIT) with drop level and size.
- Blighted maps read as "Blighted Map", which no rule names.
- Unidentified items failed `HasExplicitMod =0` and `<N`.
- `ZanaMemory`, `Exceptional`, `ShaperItem` and `ElderItem` were undecided.
- `MapTier` and `GemLevel` on other items, and `EnchantmentPassiveNum` on unenchanted ones, were undecided.
- When the parser doesn't know an item: magic map names, influences and vestigial were lost, and a stack of 1,234 read as 1.

Zana memory detection reads a "Zana's Memory" line, which I haven't seen in a real copy. Any other map counts as not one.

Local checks: typecheck, lint, all unit tests pass.
