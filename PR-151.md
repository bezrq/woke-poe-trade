_Requested by **Guy**_

Guy's pick A from the [mocks](https://claude.ai/artifact/Tyc9XyZE9wA2TqMnUgFzHx): WOKEPOET-77.

## What changes
- **Map mods tabs:** Maps, Heist and Charts, plus an Include T17 mods switch on Maps. Nightmare maps are the T17 pool, so one switch covers both.
- **T17 switch off:** T17 mods leave the list and the map search. Their ratings stay, and checking a T17 map still flags them.
- **Sorted list:** picked mods head each list under Avoid, Careful and Want. This replaces the picks block above the list. The order refreshes when the view changes, so a row doesn't jump while it's being rated.
- **Verdict card:** now also covers heist contracts, blueprints and charts. Heist items have no juice score. Charts keep it, since they show rarity and pack size.
- **Removed:** APT's old map card and the 343-row list in Item info settings. The page is now "Item info", with a link to Map mods.
- **Saved marks:** one more import from the old list, for marks made since the first. A mod already rated keeps its rating.

## Behaviour to know
- With the Map mods module off, a map now opens plain item info instead of the old card.
- Ratings are shared by mod text, so an Avoid set on Charts also goes in the map search. Heist picks never do.
- The Charts list is hand-picked from poedb's chart table, because the game data doesn't tag chart mods. "adjacent Areas" and "all Voyage Areas" lines aren't in the app's stat data, so they aren't listed and a card would show them as not recognised.
