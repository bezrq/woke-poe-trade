_Requested by **Guy**_

Guy's pick A from the [mocks](https://claude.ai/artifact/Tyc9XyZE9wA2TqMnUgFzHx): WOKEPOET-77.

## What changes
- **Map mods tabs:** Maps, Heist and Charts, each with its own ratings and its own regex row, plus an Include T17 mods switch on Maps. Nightmare maps are the T17 pool, so one switch covers both.
- **T17 switch off:** T17 mods leave the list and the map search. Their ratings stay, and checking a T17 map still flags them.
- **Sorted list:** picked mods head each list under Avoid, Careful and Want. This replaces the picks block above the list. The order refreshes when the view changes, so a row doesn't jump while it's being rated.
- **Verdict card:** now also covers heist contracts, blueprints and charts. Heist items have no juice score. Charts keep it, since they show rarity and pack size.
- **Removed:** APT's old map card and the 343-row list in Item info settings. The page is now "Item info", with a link to Map mods.
- **Saved marks:** one last pass over the old list takes heist marks only, and moves any heist marks out of the map ratings. Map marks aren't re-imported, because a missing one may have been un-rated on purpose. A config that never imported gets the full import, sorted by tab. Charts start empty.

## Behaviour to know
- With the Map mods module off, a map now opens plain item info with a line saying to turn it on, instead of the old card.
- The regex hotkey still pastes the Maps search. Heist and Charts searches use their own Copy and Stash buttons.
- The Charts list is hand-picked from poedb's chart table, because the game data doesn't tag chart mods. "adjacent Areas" and "all Voyage Areas" lines aren't in the app's stat data, so they aren't listed and a card shows them as not recognised. The same goes for revealed Voyage implicits, which the data has no implicit wording for.
- An unidentified item no longer gets a verdict.
- Heist shows one row per mod, covering its "increased" and "reduced" wordings together. A search can't split them, so the card rates them the same way.
- Highlight and auto-trim are per tab. Chart and heist search tokens are at least 5 letters, since their random names can't be listed; a longer name could still match by chance.
