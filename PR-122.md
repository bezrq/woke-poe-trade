_Requested by **Guy**_

The top tab bar wrapped to two rows and sat on the game's buff row. Guy picked the side rail plus launcher from the [mocks](https://claude.ai/artifact/KbQejf7usezNPEXfrcc35S).

**What changes**
- A rail on the left edge: app mark, Tools, settings and search, pins, other open tools. Names show on hover, and a gold mark shows what's open.
- Tools opens every tool by module group, with one box for search and item paste. A pin button on each row keeps a tool on the rail.
- Ctrl V anywhere in the overlay outside a text field price checks a copied item. It does nothing while Settings is open.
- Once per config, the rail moves below the buffs, and pins reset to settings, search, Market tracker, Boss runs, Map scan and Loot filter. Moved rails stay moved, and the launcher opens toward the screen from either side.
- The old × and "removed from bar" list are gone, since every tool is in the launcher.

**Behaviour to know:** Esc still closes the whole overlay, because the main process handles it. Clicking a row to open a tool closes the launcher, which differs from the mock, because otherwise it blocks the new window until dismissed.

**Checks:** typecheck, lint, 1790 unit tests and build pass, as do the tab-rail, app-icon and price-check e2e specs (19 tests). An adversarial review ran and its findings are fixed. Not tried on the live overlay yet. toolkit.spec.ts wasn't run: it fails on load with a MODULES import error, which predates this branch.
