_Requested by **Guy**_

Starting the app before PoE left "Client.txt not found" on the health card for the whole session, even though the log was found and being read.

**Cause.** The overlay asked for about 10 s, then memoized the miss, and `followGameLog` only called `onTail` once. Main did recover when the game window attached (`gameStarted`), but nothing told the overlay.

**Changes**
- Main broadcasts `game-log-opened`. `followGameLog` re-reads the tail on it when the log was missing or has changed, so the warning clears and missed lines replay. There's no polling.
- `logTail` no longer memoizes a miss, and re-reads when the app moves from a stand-in to the running game's log.
- Auto mode's stand-in before the game runs now checks the registry and Steam libraries (`findGameLogs({ quick: true })`), so an install off C: is found up front. It skips the all-drive sweep because this runs on every start.
- A set path or running-game path that doesn't exist yet is watched until it appears. Its existing lines come from the tail only, never as live lines.
- Trades uses `followGameLog` too, so it restores recent offers when the log is found late.
- If the game starts during the finder's search, its log wins over the guess.
