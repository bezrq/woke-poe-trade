_Requested by **Guy**_

More fixes from the [overlay core critique](https://claude.ai/artifact/Du1efrqGyeBo1LyyHQHtTw): WOKEPOET-50, 54, 56, 59, 61, 62, and the logging part of 53.

## What changes

- **Sleep (50):** on `powerMonitor` resume the uiohook restarts. Held mouse buttons also clear on resume and when the game loses focus, since a stuck entry stopped the dock catching the mouse.
- **Busy port (54):** falling back from 8585 is logged and shows a notice, because browser storage looks empty on another port.
- **Long sessions (56):** a reading every 5 minutes for a day, shown as one line on the Performance page. Logs are capped at 256 KB in both processes.
- **Clipboard (59):** the restore window goes from 120 ms to 250 ms, so a lagging game is less likely to paste your own text and press Enter. Images now survive a restore. The default stays off.
- **Display changes (61):** hover zones keep their overlay position and convert it again when scaling changes or a monitor comes or goes.
- **Held keys (62):** a press under 80 ms after the last one for that key counts as a key repeat and is ignored. The pause before a key starts repeating can still let one extra press through, and I couldn't confirm whether Windows repeats these hotkeys.
- **Updates (53, logging only):** updater errors reach the log. Rollback and signing are still open.

## Testing

`repeat-guard.test.ts` is new. Typecheck, lint, unit, main and e2e tests ran locally. Sleep, real display changes and clipboard images can't run in the test host and weren't tried on Windows.
