_Requested by **Guy**_

Hovering an item in the Market tracker showed nothing. This adds a shared item tooltip (Guy's pick from the mocks, C + P1): the game's tooltip look plus a price strip with the 7-day trend, beside the panel.

## What changed
- `v-item-tip="{ name, type?, variant? }"` works on any row. It's on the market tracker, boss drops, farming, league investing, atlas, mechanics, session analytics, loot filter (Rules, Prices, add-item search) and price check related items.
- `GameTooltip` moved from `pob-builds` to `ui/tooltip` and is mounted once in the overlay, so the build panel shares it.
- Foulborn uniques now get art in market lists.

## Data
New English pack in `renderer/public/data/tips`, loaded on first hover: 3.4 MB on disk, about 550 KB compressed. Rebuild each league with `npm run tip-data -- <league>`.

| File | Source | Size |
|---|---|---|
| `uniques.json` | poe.ninja (league, then Standard) | 984 KB |
| `gems.json` | RePoE, every level | 2,069 KB |
| `items.json` | RePoE, plus tattoo effects from Path of Building | 164 KB |
| `bases.json` | RePoE | 62 KB |

## Known gaps
- 54 older uniques aren't on poe.ninja, so they show only name, base and price.
- Divination cards have no flavour text: the only source was the wiki, which blocks scripts.
- Gem quality lines appear only for "% increased" style stats. Others use units the data doesn't explain.
- Essences show their description, not the per-slot mods.
- Market rows lost their hover hint with the poe.ninja type, as it would double up with the tooltip.

## Checks
Run locally on the merged branch: typecheck, lint (no errors), 1966 unit tests and build pass, plus e2e `item-tip` and `loot-filter`. Before the master merge, `pob-builds` also passed, and `price-check` passed before the review fixes. An adversarial review's findings were fixed: a tooltip stuck on pinned dock cards, gem quality units, unique stats and requirements, the build panel's unmount hide, cast time on attacks. Not tried yet on a live overlay.
