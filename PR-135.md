Guy's pick from the [mocks](https://claude.ai/artifact/CYvdou1dAxLmrbEebotkxS): U2 on a hotkey, U3 inside the overlay, M1 with a corrupted filter.

- **Alt + P from the game:** a two-pane search over prices, other items, tools, commands and settings. It has Wiki, poedb, Live listings, Trade site, Find in stash, watch, and pin to compare. Esc or Alt + P goes back to the game.
- **Launcher (Shift + Space, All tools):** the box also lists prices. A click or Enter opens the full search on that item.
- **Market tracker:** a search row over every saved price, on both tabs, replacing the watchlist's add box. A Vaal orb button cycles all, only corrupted and no corrupted, on Movers too.
- **Old Item search:** its icon opens the new search. The window stays only for the heist gem reader.

Limits: poe.ninja only prices corrupted items for gems, so the filter only affects gems. Items outside the saved prices (rares, bases, flasks, cluster jewels) get links but no price.
