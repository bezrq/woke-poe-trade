_Requested by **Guy**_

Death recap now reads a map's mods from the game's own list when you enter it, so a recap has them with no Alt + M. WOKEPOET-132.

- 3 s and 8 s after "You have entered" the overlay screenshots the top right corner and OCRs the blue lines, only while the game has focus. It only looks; nothing goes to the game.
- The result beats a check and shows as "From screen", unless it found fewer lines than what's already saved. Totals and "Area is corrupted" are left out.
- With the list collapsed, nothing is read and checks work as before. The OCR worker only loads if blue text is there, so that case costs a screenshot. With the list open, the worker usually reloads each map (off the main thread, 100-200 MB, idle out after 2 minutes).
- Missing OCR files stop the reads until restart; other failures retry on the next map.

**Checked:** Guy's real screenshot is now a fixture: all 12 lines read correctly and 8 mods matched, in about 0.8 s. A new fake-game spec runs the whole path with the real OCR worker. Unit tests, OCR tests, map scan spec, types and lint pass. Adversarial review ran and its fixes are in.

**Limits:** not tried on a real map yet, nor with the minimap open, where the list can shift. There's only one screenshot, at 2560x1440: the review saw lines lost when it was scaled to 1080p, which only approximates native rendering. A map with a single mod line is not read, since one line can't be told from a tooltip.
