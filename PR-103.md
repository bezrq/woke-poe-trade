_Requested by **Guy**_

First of the filter test and audit PRs. Real NeverSink filters at every strictness level now go through the parser and writer.

**Tests (`filter-parse.test.ts`):** byte-for-byte round trip, every live block found, every rule line read, each line rewritten the same, meaning unchanged after a rewrite, rewriting is stable, and the save check accepts every real rule. Also hand-written and FilterBlade layouts, and the save check's list against the official condition list. `WOKE_NEVERSINK_DIR` runs the same checks over any folder; a one-off run over all styles and over my local filters passed.

**Bugs found and fixed**
- `HasExplicitMod >= 3 "A"` (space before the count) read 3 as a mod name.
- `Import` was read as a rule of the block above.
- A rule after a blank line or comment was dropped from its block, though the game keeps reading it.
- An indented header was swallowed by the block above.
- A save header went above a byte order mark, leaving it mid-file.
- The save check refused `AlwaysShow`, `Exceptional`, `MirageMap` and `PlayAlertSound None`.
- A new league keyword in the source filter blocked saving any edit to that rule.

Local checks: typecheck, lint, all unit tests pass.
