_Requested by **Guy**_

Options C and D from the mocks.

**Next step (Leveling tab):** what changes in the next tree, skill set and item set. Trees show new points, respecs and notable names; gems show add and drop; gear shows the slots that change. "Next" is the next stage by title, past side sets, or the next in the file when titles have no stage. A skill set picked by hand with no same-named tree leaves the tree following your level. Clicking the tree card opens it on the tree.

**Passive tree in the overlay:** the Passive tree button opens a panel instead of a browser, with your allocated points in gold, a tree's new points in green and respecs in red. Wheel zooms, drag pans, hovering a node shows its stats. The website link is still in the panel's header.

The tree data is `public/data/tree/passive-tree.json` (196 KB, loaded on first open), built by `npm run tree-data` from PoB's `TreeData/3_29/tree.lua`. A build saved on an older tree still draws, but nodes GGG removed since then aren't shown, though they count as points.

Stats on a levelling build now say which set they're saved for.

Local checks: unit tests, PoB e2e spec with a new tree test, `vue-tsc`, eslint, `vite build`, main `tsc`. Captured with Guy's real zizworb build in headless e2e. Not tried in the game yet.
