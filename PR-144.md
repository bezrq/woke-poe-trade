_Requested by **Guy**_

The Tools box only listed tools already placed on the overlay, with the rest behind "Add another tool". Guy found that counter-intuitive.

**What changes**
- Every tool is listed, in its module group.
- Clicking a tool that isn't placed yet places and opens it, without pinning it.
- Switched-off tools are greyed and tagged Off. A click turns the module on and opens the tool.
- Campaign tracker is tagged Icon row, and a click opens its settings, since it has no window.
- The separate add list is gone. Copies of cheat sheets and stopwatches come from "Add another copy" in the right-click menu.
- Placing a tool now pushes the host config, so its default hotkeys and game log tailing start straight away. Before, they waited for a restart or a Settings edit.
- With prices showing, Enter only opens a placed tool, so typing "essence" to price one doesn't switch on the Essence scan.

Price check and item info aren't listed: they act on an item, so the box's paste and search cover them.

**Checks:** typecheck, lint, 2045 unit tests and build pass, plus the tab-rail, search and app-icon e2e specs. An adversarial review ran and its findings are fixed. Not tried on the live overlay yet.
