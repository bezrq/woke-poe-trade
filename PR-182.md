_Requested by **Guy**_

Fixes the main part of WOKEPOET-51. Guy picked the downloader, so new items work without a release, an installer or a restart.

## How it works

1. A minute after start, then every 6 hours, main reads `renderer/public/data/data-version.json` from this repo's master.
2. If its version beats both the app's bundled data and any earlier download, main downloads `items.ndjson` and `stats.ndjson` for the current language to user data. Each must match its SHA-256 in that file, then the set moves into place in one step.
3. The page fetches them from the local server (`/live-data/…`, behind the own-page check), builds the lookup tables and runs the same stat checks bundled data gets. If they fail, nothing changes.
4. The new data takes over through the existing live bindings, the way a language change does.

Later runs load the download at startup. An app update bringing data as new removes it.

## Releasing new data

Merge the new `.ndjson` files, then run `node src/assets/bump-data-version.mjs` in `renderer/`. A test fails if the data changes without this. Merging to master is what ships it, so master's data goes to every player straight away.

## Limits

- New data still comes from Awakened PoE Trade's "update data" commits; this repo has no generator.
- Only items and stats update. `client_strings.js` and `item-drop.json` still need a release, so a league that adds new item text labels may not parse until then.
- `format` in the version file guards against data an older app can't read: a different number is left for the next release.
- The price check uses new data straight away, and an open one keeps what it already parsed. Some other features keep their own copy until a restart: the loot filter's prices and item search, the search window's item list, map mods, and game icons, lab gem icons and PoB item art. They show old data, with no crash; a follow-up could refresh them.

## Not in this PR

Falling back to raw text on an unknown item, and clients in languages the app doesn't offer.

## Testing

New tests: the built lookup tables are identical to the build's for all four languages; a new item is findable straight after the swap; missing stats and broken data are refused with the old data kept; hash, format, version and language handling for the download. Typecheck, lint, unit, main and e2e tests ran locally. The real download from GitHub hasn't run, since `data-version.json` isn't on master until this merges.
