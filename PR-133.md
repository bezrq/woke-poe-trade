Fixes WOKEPOET-45, WOKEPOET-47, WOKEPOET-52 and WOKEPOET-48, from the [overlay core critique](https://claude.ai/artifact/Du1efrqGyeBo1LyyHQHtTw).

## What changes

- **Failed item copy:** main already sent `item-text-failed`, but only the loot filter's sample key listened. Every other copy hotkey now shows a toast. The loot filter keeps its own message.
- **Second launch:** used to exit with nothing visible. It now shows a tray notice with the overlay key.
- **Client.txt:** the watcher kept a stale handle and read nothing after the file was cleared or replaced, which stopped every log feature silently. It now reopens. If the file is deleted it lets go of the handle, so the game can create a new one, then follows that.
- **Hotkey clash:** two actions on one key lost both. The first now stays. Opening the overlay always wins its key, and a test-only entry never takes a real action's key. Settings still warns about the clash.

## Testing

New: `game-log-watcher.test.ts` (real files and the real watcher), `pick-actions.test.ts` and the `item-copy-failed` e2e spec. Typecheck, lint and unit tests ran locally. The tray notice can't be tested headless and wasn't run on Windows.
