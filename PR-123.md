_Requested by **Guy**_

First fixes from the loot filter critique (WOKEPOET-34).

**Measured with poe.ninja prices from 2026-11-05 on NeverSink 8.20.2**, with the 20c net on, valuable plain drops that stay hidden:

| Level | Allflame before | Allflame now | Hardcore before | Hardcore now |
| --- | --- | --- | --- | --- |
| Very strict | 15 | 0 | 26 | 0 |
| Uber strict | 32 | 0 | 49 | 0 |
| Uber plus | 68 | 0 | 94 | 0 |

**Safety net**
- Walks the rules for a plain map drop. It used to trust the first rule listing a base, so Replica and Foulborn rules read as "this base shows".
- Counts thin markets, and ignores "Cheapest unique".
- Covers astrolabes, invitations, embers, vials, corpses, runegrafts and reliquary keys, which have exact prices but sat outside the groups it checked.
- Catches a stack worth the line, at the stack size that gets there.
- Remembers what was valuable, so with no prices, or a category missing from the feed, it still judges the filter as it stands.
- Leaves alone your own rule for a base, your own move down, and "Not for me" on a hidden item. A rule of yours with no Rarity doesn't count for a unique. Hiding a whole tier doesn't count either, so the net still catches what's valuable in it.
- A new list saves itself when nothing of yours is unsaved. That save types nothing into chat, and the dock says it takes effect at the next reload.
- Has an alert sound, and takes the colour-blind colours.

**Prices**
- A unique with only variant lines is judged by its best line, never its cheapest. Tiers use the best real market. A unique sold per base uses that base's line. Voices no longer plans a move to hideable at 1c.
- Moves carry their league and stay out of the file in another one. A league switch rewrites the file by itself.
- Prices over a day old warn. Over three days old, no moves are offered.
- Going down a tier takes a 50% margin, going up 20%. A price that jumped this week waits. A move that would hide an item starts unticked.
- A move gives way when NeverSink has re-tiered the item, and the update check counts those.

**Other**
- "Show it", "Back to NeverSink's tiers", "Not for me" on a hidden item, and "Unlock" of your own move all save.
- Auto strictness waits while you have unsaved changes.
- Custom sounds use `CustomAlertSoundOptional`, so a missing file can't make the game refuse the filter.
- NeverSink downloads come from the latest release, falling back to master. An older version is never offered as an update.
- A copy follows its source filter when nothing of yours is unsaved.
- The game's load result is read again a minute after saving and on each town visit.
- The rule builder warns about a base the game may not know.

**Not in this PR:** typing `/itemfilter` with no key pressed is left to WOKEPOET-36. Hardcore safe mode waits on Guy's pick (WOKEPOET-39).
