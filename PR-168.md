_Requested by **Guy**_

Guy's pick from the [mocks](https://claude.ai/artifact/18ihCQ5vBMjx9mZUXTJQwU): reload option A plus a key hint. Follow-up to #126, which stopped the app reloading the filter by itself (WOKEPOET-40).

## What changes

- The loot filter's dock icon shows **Reload** when a saved filter isn't in the game yet. That covers a held save, a strictness ladder switch, and a safety net update.
- Its card says the game still uses the old filter, with **Reload now** and "or press Alt + Shift + R".
- New `reloadHotkey`, default Alt + Shift + R (Alt + R is Map scan's rolling mode), listed on the Hotkeys page and in search. It's only registered while chat reload is on, releases every key first, and sends right away, so extra presses can't pile up and fire later. With nothing saved yet it says so.
- Notes now name the key.
- The two old text notes about a waiting reload are gone, as the card replaces them.

## Differs from the mock

No Undo on the card. The ladder's toast still has it.

## Testing

A new e2e spec: a save with nothing typed, the Reload icon, the card, then the key sends exactly one `/itemfilter`. Typecheck, lint, unit, main and e2e tests ran locally. Not tried in the real game, and a click on Reload now isn't covered by the spec.
