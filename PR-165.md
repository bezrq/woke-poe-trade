_Requested by **Guy**_

The poelab window stayed over the game after leaving Shift+Space. It now leaves with the overlay and returns with it (WOKEPOET-94, option A from the mocks).

- **While you play:** a Labyrinth dock icon with the difficulty letter shows while a layout is open or you're in the lab. Hovering shows the map in a 45rem card, up from 34rem, so poelab's notes stay readable.
- **When it ends:** closing the layout or the window, leaving the lab, or the midnight UTC reset outside the lab.
- **Layout hotkey outside the overlay:** holds the card open until pressed again, and never opens the window. With the icon switched off in the dock settings, it opens and closes the layout, which shows with the overlay.
- **Difficulty:** every plaza logs level 33, so the first room now corrects the badge and map. The plaza itself still guesses Normal; WOKEPOET-87 covers that.

Not covered: the card uses the window's image when poelab's page has loaded there, else a direct fetch. If poelab answers that fetch with a 403 (WOKEPOET-87), a layout opened by hotkey shows the error until you open it in the overlay. Neither path has run against real poelab in Electron.
