_Requested by **Guy**_

Listing rows showed no mods, so you had to open the browser to see why one was cheap, and corrupted copies looked the same as clean ones.

- Hovering a listing shows its item in the shared game tooltip: implicits, enchants, mods, defences, sockets and item level. The trade site already sends this, so it costs no extra requests.
- Corrupted copies get a tag and their own row, so they no longer merge with clean copies at the same price.

Limit: a merged row shows its first listing's item, and its other listings may have different rolls.

This is option A from the [mocks](https://claude.ai/artifact/T7Ty4PqX9C1iKtLGvdqovp), with the tag beside the count where the mock had a separate column, so it fits the window's width.

Checks: adversarial review, which caught that the real API sends mods as objects. The mapping now handles that and is tested against 4 items captured from the live trade API, all fractured rares and magic items from Standard. New tests, full unit suite, typecheck, lint and build. I didn't open the price check window.
