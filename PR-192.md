_Requested by **Guy**_

Master CI has been red, and each job stops at its first failure, so the steps after those failures have not been running. This clears the blockers and the flakes that turned up once the rest ran again. WOKEPOET-112.

**Blockers**
- Type check: `bump-data-version.mjs` gets JSDoc types, and the stale `@ts-expect-error` in `live-data.test.ts` goes.
- OCR: `map-real-01` and `map-real-11` now expect the two-line mod as well as its single lines. The parser has reported both since #110, and `map-mods.test.ts` asserts that, so the fixtures were stale.
- `toolkit.spec.ts` stopped a whole Playwright run from loading on Node 20. Playwright's loader emits ES module syntax for renderer files, and only Node 22 accepts that in a folder with no `type`. Specs now load it through `require` in a shared helper, and `perf.spec.ts` had the same problem.

**A real bug behind a flake**
A reloaded overlay reuses hover zone ids, and main kept their "mouse inside" state without telling the new page. A dock card then stayed shut until the mouse left the icon and came back. `main/src/woke/hover.ts` now tells the page when it registers a zone the mouse is on. The next test on a worker's fake app hit this at random, and `lab-bubble.spec.ts` has a test that reproduced it every time before the fix.

**Another real bug behind a flake**
Hiding the price window starts apexcharts' delayed redraw. A new check within 150 ms removes the chart, and the redraw writes NaN into the svg and logs page errors, which failed the drag test at random. The chart's box has a fixed size, so `PriceTrend.vue` turns those redraws off. A new test failed 6 of 6 runs before the fix and passes 6 of 6 after.

**Flake**
The drag test measured the window while exchange offers could still arrive and grow it. It now waits for them.

**Testing**
Locally: lint, type checks, unit tests, OCR and perf pass, and the fake-game suite passed twice in a row with no retries before #193 merged, and the specs #193 touches pass after it (262 passed, 34 skipped, which are the env-gated demo and landing shot specs). Adversarial review found no defects.
