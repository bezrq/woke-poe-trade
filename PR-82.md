### Trade search window can't be moved or resized

**Trade search panel now drags and resizes, and the campaign tracker's guide card no longer clips at the right edge.** Causes: inline style on WPanel beat the saved size; webviews took the mouse mid-drag; default size overflowed the screen, hiding the close button and resize handle; whole-widget clamp blocked moving right/down. Campaign strip was only blocked rightward at the screen edge and had no move cursor. Same fix applied to Labyrinth. Validation: 161 vitest tests pass including new test/woke/panel-drag.test.ts; browser test with Guy's saved layout against a stand-in host: every widget drags, trade panel 1032x806 fits at default, resize applied 852x616. Not tested in the real Electron or Tauri overlay, so the webview mouse fix is unconfirmed live. Overlaps "Add minimize button" thread in WPanel boxStyle, so whichever lands second rebases. No docs needed: no documented behaviour changes.
