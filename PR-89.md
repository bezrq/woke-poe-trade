_Requested by **Guy**_

Packaged builds take minutes, so this adds a one-command dev preview: a dedicated clone running Vite hot reload and Electron, which can switch to any branch in about 10 seconds.

## What changed

- `scripts/woke-dev.cmd` and `scripts/woke-dev.ps1`: the launcher, with `woke-dev [branch]`, `status`, `stop` and `packaged`. They are installed next to the clone so branch switches can't touch the running script.
- Only one copy runs at a time: the launcher stops the packaged build first, because all builds share a data folder and single-instance lock.
- A branch switch is refused while the clone has uncommitted changes, and the running app is left alone.
- Generated data index files are created before Vite starts. On a fresh clone, Vite otherwise answers for them with `index.html` and the overlay crashes on startup.
- `main/build/script.mjs` passes `WOKE_ELECTRON_ARGS` to Electron, which the launcher uses for a local debug port (`127.0.0.1:9333`).
- The tray tooltip reads `Woke PoE Trade DEV (<branch>)` in dev mode.
- `DEVELOPING.md` documents all of this.

## Tested on Guy's PC, with PoE running

- The overlay attaches at the game's full size (2560x1440) and renders with no exceptions.
- A temporary edit to `App.vue` applied live, with no page reload, and so did reverting it.
- Switching to `master` and back took about 10 seconds each way, with the overlay re-attaching.
- A missing branch, an invalid name and a dirty clone are each refused, and the app keeps running.
- Reproduced the fresh-clone failure on a spare Vite port (`text/html`), then confirmed pre-generating fixes it (`application/octet-stream`).

## Not tested

- The tray tooltip hasn't been seen live; it type-checks.
- The packaged build was restarted with `woke-dev packaged`, but the build itself is unchanged.
- Whether the dev copy survives the end of the session that started it. It runs detached through WMI for that reason.
