_Requested by **Guy**_

`game-log-watcher.test.ts` ("a big file swapped in isn't replayed") failed in CI on #207, and CI now blocks merges. It waited a fixed second, then wrote `fresh`. On a slow runner the watcher notices the swap later than that and skips to the end of the file, so `fresh` is skipped too.

The test now writes `fresh` until it arrives. The existing `appendUntilSeen` helper wouldn't help, because it repeats a `nudge` line and not the line it waits for, so a skipped line would never come back. Test-only change. WOKEPOET-112.
