_Requested by **Guy**_

Adds a Challenge guide module (WOKEPOET-8): a hotkey shows CraniumCarnage's challenge guide in an overlay panel, restyled to fit the toolkit.

- **List:** all the guide's challenges with a filter and a hide-finished toggle. Clicking one scrolls the guide to it. Ticking in the list uses the site's own tick button.
- **Sync:** when the panel opens, or on the Sync button, a temporary webview reads the game's public profile page and ticks finished challenges. It only adds ticks, and shows part-done counts such as 3/4. It reruns on open if the last sync is over 5 minutes old.
- **Setup:** only the account name is needed, with no login. While it's blank, the settings page shows an "Account name · not set" link and a warning, and the panel shows a banner. Manual ticks still work.
- **Hotkey:** it takes overlay focus so you can scroll at once. Pressing it again or Esc returns to the game.
- **Dock icon:** optional and off by default. It shows the count and the next three challenges.

The screen-reading hotkey for the game's own challenges window is not included. It's a follow-up.

## Testing

- Unit tests added in `renderer/test/woke/challenges.test.ts`. The renderer suite passes (175), and type checks and lint on the changed module pass.
