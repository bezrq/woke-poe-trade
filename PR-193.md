## Summary

The price check jumped around as filters changed and results loaded. A recording of Chromium's layout shifts through a full check found each cause.

```diff
 <CheckedItem>
   verdict slot
-    empty until the first search, then pushes the mods down
+    holds the verdict's height from the start and through errors
   filters
   Search row
-    below the listings, appears when the listing unmounts
+    takes the toolbar's spot; passing over it doesn't search while results are dimmed
-  <TradeListing v-if="doSearch" :filters="live" :stats="live">
+  <TradeListing v-if="searched" :filters="snapshot" :stats="snapshot" :stale="!doSearch">
```

| What moved | Fix |
| --- | --- |
| Ticking a mod removed the results and verdict, so mods jumped up | Last results stay, dimmed, until the next search |
| "No data" flashed on a second line before listings arrived | Verdict stays on "Reading listings" until they do |
| First search pushed the mods down | Band holds the verdict's height |
| Toolbar buttons slid when results loaded | They keep their place, hidden |
| Reloading shrank the table | Loading rows take the last results' count |
| Listing count line appeared late | It keeps its line |
| Mod worth tags changed width | One width from "8%" to "~24c", room held on rares |
| A search with no results added a line | Note stays on the row |

While results are dimmed, a running Measure or Widen stops, and an error clears so Retry can't use old filters.
