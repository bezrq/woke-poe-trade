Bugs 111-120 of the bug hunt.

- **111. PoB: "20% quality" read as level 2.** The number regex backed off from "20" to "2". "10.5" and "100%" had the same problem, so a set could be picked for the wrong level.
- **112. PoB: "late" inside a word read as endgame.** "Full Plate", "Template".
- **113. PoB: in the Epilogue with no level yet, the first set was picked.** The act table stops at act 10.
- **114. PoB: transfigured gems were missing from the next-gems list.**
- **115. PoB: mods of alt variants were hidden.** Watcher's Eye and other items with `Selected Alt Variant` showed only the first pick's mods.
- **116. PoB import: pasted junk showed "incorrect header check".** It now says the code isn't a build.
- **117. Farming: typing a strategy failed when an Atlas widget had never mounted** (its module off), so scarab costs weren't filled.
- **118. Atlas: Use in farming failed on a Farming widget that had never mounted.** The strategy and costs now also survive its first mount.
- **119. Analytics: maps left out still counted** in maps per hour, cost per map and time in maps.
- **120. Analytics: the CSV didn't add up to the session.** Loot not tied to a map, typed-in chaos and maps counted by hand were missing; they now get their own row.
