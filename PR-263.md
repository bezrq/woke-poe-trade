Guy picked B + C from the window opacity options.

## What changes
Settings → Look & icon row → Overlay:
- **Panel opacity** slider (30–100%, default 100%). It fades overlay panel backgrounds and leaves text and icons solid.
- **Solid when the mouse is over a panel** (on by default, shown below 100%). CSS `:hover`, so it works while the overlay is open or has the mouse (dock icons and cards). It doesn't work while the game has focus.
- **Darken the game while the overlay is open** is now a 0–60% strength slider instead of a toggle. The slider writes black at that alpha. Old colours such as APT's grey 15% default read back by their alpha.

## How
- Themes and the price check now set `--w-panel-base`, `--w-panel-2-base`, `--w-panel-solid-base`, `--w-pc-window-base` and `--w-pc-well-base`. `theme.css` derives the usual tokens from these.
- Below 100%, `[data-woke-panel-see]` adds a rule on each element under `#overlay-window` that mixes those tokens with transparent. At 100% the rule is off, so it costs nothing.
- `*:hover` puts the base colours back. Each element works its value out for itself, so only the panel under the mouse goes solid and the others stay see-through.
- The setting is stored in localStorage, the same way as theme and text size.
- Canvas and webview readers (BuildTree, Challenges guide) read the `-base` tokens so they stay opaque.
