_Requested by **Guy**_

Dev mode threw away every settings change on restart, which kept costing Guy dropped widgets and loot filter editor state. The dev preview now saves to the real config, the same way the packaged build does.

## What changed

- `ConfigStore` saves in dev mode when `WOKE_DEV_SAVE_CONFIG` is set. Only `scripts/woke-dev.ps1` sets it, so a plain `npm run dev` from any other clone or worktree still can't touch the player's settings.
- The launcher copies `config.json` to `.woke-dev\config-backups` on each start and keeps the newest 20, because a preview branch can now change real settings.
- `DEVELOPING.md` is updated.

## Compatibility

Dev and packaged read and write the same file through the same `upgradeConfig`, so they stay compatible as long as both are on the same config version. A branch that bumps `configVersion` writes a config that an older packaged build won't downgrade, which is what the backups are for. Saves still go one at a time and replace the file in one step, and the single-instance lock stops both running at once.

Theme, scale and other browser-stored preferences stay separate, because dev runs on a different origin.

## Tested

- `tsc --noEmit` in `main/`.
- The launcher script parses.
