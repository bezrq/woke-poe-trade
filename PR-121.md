_Requested by **Guy**_

Edit history, option C from the mock. Stacked on #120, so merge that first.

**Timeline (Changes tab)**
- Every change to your filter settings is a step, saying what changed, such as "General currency › Tier 1: font size 40 → 45". It watches the settings instead of each button, so own rules, presets and price moves are covered too.
- Ctrl+Z and Ctrl+Y step through it. A step has Undo if it's the latest, or Back to here. Going back doesn't touch the file until you save.
- Quick changes, like dragging a slider, gather into one step. An Undo note keeps the list in step.
- The last 50 steps survive a restart. Each keeps only the parts that changed, so 200 price moves aren't saved again with every font size.

**Reset per setting**
- A dot marks each setting that differs from the filter as it came. Click it to go back to that value. The Alt + F card has the dots too.

**One difference from the mock:** older steps have "Back to here", not their own Undo. Undoing one step from the middle while keeping later ones can conflict, so it isn't offered.

**Tests:** `filter-timeline.test.ts`, store flows in `filter-flows.test.ts`, and an e2e spec for the dot, the list, Ctrl+Z and Ctrl+Y.
