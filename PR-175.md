_Requested by **Guy**_

Fixes WOKEPOET-46 and WOKEPOET-49, as drawn in the [mocks](https://claude.ai/artifact/18ihCQ5vBMjx9mZUXTJQwU).

## What changes

- **Tray status:** the tooltip and the top menu line say "Waiting for Path of Exile", "Attached: press Shift + Space in game", or that PoE runs as admin.
- **Exclusive fullscreen:** one Windows notice per launch. The overlay library doesn't report fullscreen on Windows (`is_fullscreen = -1` in its `windows.c`), so this reads `fullscreen` and `borderless_windowed_fullscreen` from `production_Config.ini`, read again each time the game attaches.
- **Reset overlay key:** a new tray item sets it back to Shift + Space, saves, and confirms once the page has taken it. If the page doesn't respond within 3 s, the notice says so instead.
- **PoE key clashes:** all `ACTION_KEYS` are read, and a hotkey on one of those keys shows a quiet note on its row. It doesn't count as a clash anywhere, since taking a game key can be deliberate.

## Known limits

- The config file only changes when the game writes it, so switching to fullscreen mid-session isn't noticed until the next attach.
- With Settings open, it keeps showing the old overlay key until reopened; the reset still applies.

## Testing

`game-settings.test.ts` is new, with values in the same format as a real `production_Config.ini`. Typecheck, lint, unit, main and e2e tests ran locally. The tray can't run in the test host, so the status line, notices and reset haven't been run. Not tried on Windows yet.
