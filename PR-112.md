_Requested by **Guy**_

Fourth filter test PR: what the editor adds on top of a filter, plus the Alt + F card.

**Tests**
- `filter-rules.test.ts`: every rule builder condition, every preset at every strictness level (each one checked by running items through the result), share codes.
- `loot-filter.spec.ts`: Alt + F shows the card alone, and its Hide key writes an own rule to the file.

**Bugs found and fixed**
- The editor offered `Minimal` in normal filters. The official docs say it only works in Ruthless filters, so choosing it risked the game refusing the whole filter. It's now hidden and refused unless the filter is Ruthless.
- A share code or saved config with a broken edit, such as a style with no patch, could stop the filter from opening. Edits are now checked by kind, and broken ones are dropped.
