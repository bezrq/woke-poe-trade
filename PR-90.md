### Build panel tooltip can stay stuck on screen when the overlay closes

**Guards the build panel tooltip against getting stuck.** It now closes with the overlay, on window blur, and on scroll. Also restores the hover text on truncated gem sources and stops a duplicate key when a gem is listed twice in a link.

Validated: vue-tsc and eslint clean, 181 renderer tests pass, `testing/e2e/pob-builds.spec.ts` passes. The stuck tooltip did not reproduce on the fake game: the new overlay-close test also passes without the guard, so it doesn't prove the fix. It's a guard for the real overlay, which the tests can't exercise. No docs needed: no visual or API change.
