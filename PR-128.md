_Requested by **Guy**_

Fixes WOKEPOET-41 and WOKEPOET-55, from the [overlay core critique](https://claude.ai/artifact/Du1efrqGyeBo1LyyHQHtTw).

## Why

The local server accepted a websocket from anywhere on a fixed port, so a web page in the player's browser could act as the overlay: type in chat, overwrite settings, and call toolkit handlers, including `pob-open`, which starts a program named in the request.

## What changes

- Every HTTP route and the websocket check the request first. Host must be a loopback name, which stops DNS rebinding. Origin, when sent, must be the page this server serves, and `Sec-Fetch-Site` must not be cross-site or same-site.
- Routes now hang off `httpRoutes`, which is reached only after the check, so a new route can't skip it.
- `--listen` still works from other machines: this PC's own addresses count as Host too, so DNS rebinding stays blocked, and `pob-open` won't start a program. Proxied pages get `Content-Security-Policy: sandbox`, so another site's page can't run as the app's page.
- A missing file is a 404 instead of an uncaught stream error recorded as a crash. Queries are ignored, and `..` can't leave the served folder.
- Bad socket messages are ignored, a hotkey before the page connects no longer throws, and unhandled rejections go to the log.

## Decisions

- **No per-run token.** Browsers set these headers themselves and pages can't forge them. Local programs already run as the player. This also keeps page URLs and the tray's Open in Browser unchanged.
- **`pob-open` still takes the program path from the request** in a normal run. Only the app's own page can reach it now. Reading it from saved settings isn't reliable, because settings aren't on disk until Settings closes.
- **Port stays 8585**, because browser storage is tied to it.

## Testing

`request-guard.test.ts` covers the rules, and `server-guard.test.ts` runs the real server with a real websocket. Typecheck and main tests ran locally. Not run in the packaged app or in game yet; dev mode's Vite proxy forwards the page's own Host and Origin, which the tests cover as a case.
