## Summary

A tally of the drops you choose, plus maps run, on a dock icon. PoE doesn't log pickups, so drops are counted by you.

```text
<DropCounter> (woke/drop-counter)
  <DockItem> badge = maps run; hidden in campaign zones
    card: layout 'list' (default)   +1 per row, maps -/+
          layout 'strip' (setting)  tile click +1, right-click -1
    "Add an item" -> opens the overlay (a card takes clicks in game, not typing)
  <WPanel> search (priced items, or any text), -/+, remove, reset, with undo
  onGameLog: isMapArea + countNewMap, same rule as Farming
  hotkey (unset by default): +1 on the hovered item, adds it if new
```

Shared change, needed so an icon can stay up through a map:

```diff
 useHoverZone
-  setInterval(send, 2000)   # one per zone, three per dock icon
+  addCheck(send)            # one shared 6 s timer for all zones
```

Mocks: https://claude.ai/artifact/SWjWD1MN7wBPLxiVVh3Pcy (Guy liked A and B, so A is the default and B is a setting).
