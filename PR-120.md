Rules tab layout A from the mocks Guy approved. Stacked on #116, so merge that first.

**Rules**
- Plain names: "Tier 1", "Identified rares", "The rest". The saved filter and edits keep the real tags, and hovering shows them.
- Item icons on tier rows and item chips.
- An add-item search on each tier, like FilterBlade's. It searches everything the filter lists plus every base in the game, and shows each result's look and current tier. It moves the item if it's in this group, otherwise adds it, and warns if an earlier rule still decides the look.
- Right-click an item for "Move to", with each tier drawn in its own look.
- × on an item takes it off the tier, or sends it back if you moved it there.
- Changed markers on groups and tiers, and Reset tier.
- Size, colours, then Sound, Beam and Map icon folded to one line each, so items stay in view. The Alt + F card uses the same editor.
- Pasting a copied item into the search box opens its rule.

`move` edits gain an empty `from` (added from outside the group) and an empty `to` (taken off the tier).
