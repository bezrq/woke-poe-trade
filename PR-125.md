## What changes

- **Landing page** (`docs/index.md` → `docs/.vitepress/theme/landing/`). It has:
  - a split hero on a real game frame
  - a "one map, start to finish" scroll story
  - every module by group, with clickable presets
  - three install steps and a FAQ

  Module names, descriptions and presets are imported from `renderer/src/web/woke/modules.ts`, so they can't drift.
- **Live demo** (`/demo/`, D1 "sandbox with key dock"). This is the real overlay build running in the browser over real game screens. A dock lets you trigger Ctrl+D (pick the item), Shift+Space, Alt+E, Alt+S and Alt+F, and the same keys work on the keyboard.
  - `docs/public/demo/shim.js` stands in for the desktop app. It serves `/config`, answers `/proxy/…` from `testing/fixtures/http`, and fakes the app's socket by replaying what the app sent for each hotkey. That replay comes from `recording.json`, which `testing/e2e/demo-record.spec.ts` records on the fake game when run with `WOKE_DEMO_RECORD=1`.
  - No renderer code changes. `docs/scripts/build-demo.mjs` builds the renderer under `demo/app/`, keeps English data only and rewrites the `/images/` paths.
- **Docs site config**:
  - base is `/woke-poe-trade/`
  - download links point at this repo's releases and read the version from `main/package.json`
  - SnosMe's Patreon, Discord and site verification are removed
  - `mpa` is off, so the story and presets run in the browser
- **README**: banner, badges, a "Try the demo" link, four screenshots, the module table, a quick start, development notes (including how to re-record the demo) and credits. `renderer/test/woke/readme.test.ts` fails if the table and `modules.ts` disagree.
- **Screenshots**: `testing/e2e/landing-shots.spec.ts` drives the real overlay on the fake game over Guy's own PoE screenshots, with the stash tab names blurred.
- **Docs workflow**: runs on master (and by hand) only. It now also installs renderer deps and builds the demo after the site.
