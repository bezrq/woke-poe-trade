_Requested by **Guy**_

Visual overhaul of the price check window, no functions removed.

- **Verdict:** compact two-line card, confidence on the card's edge, chart shorter and the 7-day change always beside the sparkline. The medium confidence badge reads OK instead of Fair, because "fair" already means the price.
- **Toolbar:** one line, nothing clips, the filter's label gives way first.
- **Listings (Improved):** one row per price with a count and a bar for how much is for sale, age as a range, listings over a week old fade, rows behind the fair range get a gold edge. Merges only when every visible column matches.
- **Classic view** stays one row per listing with no fading, in the same tidier table.
- **Tables:** no blue stripes or empty filler rows; placeholder rows while loading.
- **Filters:** item name in rarity colour, APT's navy backgrounds now follow the theme.
- The classic theme keeps APT's colours.

Grouping is in `woke/price-insight/listing-rows.ts`, unit tested. E2E added to `price-check.spec.ts`.
