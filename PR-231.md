_Requested by **Guy**_

## Summary

Guy's screenshot showed the Flips note running off the bottom of the screen and sitting off centre from the icon.

- **Cause:** the note was lifted and centred with `transform`, but its `w-enter` opening animation ends on `transform: none` and holds it (`both`), which replaced that rule. So every note hung down from its point, starting at it.
- **Fix:** the note now uses the separate `translate` property, which the animation doesn't touch. This changes every note in the app: all of them now stand on their point and are centred on it, as the code always intended.
- **Icon near the top:** a note beside an icon in the top 120 px hangs below the icon instead, however many lines it has. This replaces a fixed offset that assumed one line.
- **Card hint:** "Click to outline flips" on the Flips card now matches the size of the text around it.

## Limits

- Non-dock notes move too, since they were all affected. Only dock notes were measured; notes at the bottom of a panel were not checked by eye.
- Not checked in the real app.
