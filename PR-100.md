## What changed
- Own rules for unique maps now use the base `Map (Tier N)`. The old `Map` never matched in game, so these edits did nothing.

- Alt stays held through the copy, so items the filter hides keep their ground label.
- Save + reload and Reload now reload immediately anywhere. The card gets Reload now; quick fixes still follow "only in town or hideout".
- Preview shows hidden items by default. Back and the mouse back button return to the same pile.
- Warns on the card and in the editor when the game uses another filter. Fixes a false "couldn't load your filter" banner, and a false wrong-filter warning for local filters.
- Tells you when the game gave no item text, or when the overlay has focus. The title bar shows the Alt + F hotkey.
- The editor is seeded once, hidden, checking every hotkey for clashes, and reads nothing until it's set up or used.
