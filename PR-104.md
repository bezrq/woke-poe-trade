_Requested by **Guy**_

The launcher's settings backup could save an out-of-date file. A Claude thread's shell can see a stale snapshot of `%APPDATA%`: on Guy's PC, the shell saw a 10,292-byte `config.json` from 13:55 while the running app had a 10,591-byte one saved seconds earlier. So backups taken when a thread started the launcher didn't hold his current settings.

The copy now runs detached through WMI, the same way the app is started, so it reads the real file.

## Tested

- The same WMI copy command, run from a thread's shell on Guy's PC, produced a 10,591-byte backup, matching the app's real file.
- The launcher script parses.
- Not yet run through a full launcher start, because that restarts Guy's overlay. The next `woke-dev` start will exercise it.
